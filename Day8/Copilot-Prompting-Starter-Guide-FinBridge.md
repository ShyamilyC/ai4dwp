# Copilot Prompting Starter Guide (FinBridge)

Audience: Non-technical office staff

Purpose: Help you get useful results from Microsoft 365 Copilot in everyday work with simple, reusable prompts.

---

## Start Here: The 4-Part Prompt Formula

Use this easy formula every time:

**Task + Context + Format + Check**

Think of it like this:
- **Task**: What do you want Copilot to do?
- **Context**: What should Copilot know (email thread, document purpose, audience, deadline)?
- **Format**: How should the answer look (bullet points, short email, table, action list)?
- **Check**: What quality check should Copilot do (clarity, tone, missing actions, dates)?

### One-line template to reuse

"Please **[task]** using **[context]**. Give the output as **[format]**. Then **[check]** before you finish."

Example:
"Please summarise this email thread for me using the last 6 messages. Give the output as 5 bullet points plus 3 actions with names. Then check if any deadline or name is missing before you finish."

## Outlook: Copy/Paste Prompts You Can Use Today

### 1) Summarise a long thread and pull actions
"Summarise this email thread into:
1. What has been agreed
2. What is still open
3. Action items with owner and due date
Keep it under 150 words and use plain business language."

### 2) Draft a polite follow-up
"Draft a friendly follow-up email to [Name] about the budget approval request sent on [date].
Include:
- a one-line recap
- a clear ask
- a proposed response deadline of [date]
Tone: professional and polite, not pushy."

### 3) Rewrite my draft for clarity
"Rewrite my draft email so it is clearer and shorter.
Keep all facts, remove repetition, and make the tone suitable for a manager or colleague.
Return:
- Subject line options (3)
- Final email body"

## Word: Copy/Paste Prompts You Can Use Today

### 1) Turn rough notes into a clean document
"Turn these notes into a one-page meeting summary for the Finance Operations team.
Structure it as:
- Purpose
- Key decisions
- Risks/issues
- Next steps
Use short headings and concise bullet points."

### 2) Create a first draft from a brief
"Create a first draft of a policy update memo for hybrid working expenses.
Audience: all FinBridge staff.
Length: about 500 words.
Include: what changed, who is affected, when it starts, and where to get help.
Tone: clear, supportive, and practical."

### 3) Improve readability for non-specialists
"Edit this document for non-technical readers.
Replace jargon with plain English, shorten long sentences, and add a short FAQ section at the end with 5 common questions and answers."

## Excel: Copy/Paste Prompts You Can Use Today

### 1) Explain trends in a table
"Analyse this table and give me:
- top 3 trends
- top 3 concerns
- 3 likely causes
Then suggest 3 actions a team manager can take this month.
Output as a simple bullet list."

### 2) Build quick monthly insight text
"Using this sheet, write a monthly performance summary in plain language for leadership.
Keep it to 8 bullet points.
Include: changes vs last month, biggest improvement, biggest drop, and one recommendation."

### 3) Help with formulas and checks
"I need to track overdue invoices by days overdue band (0-30, 31-60, 61-90, 90+).
Suggest the formulas I need and explain exactly where to put them, step by step.
Then give me a simple check list so I can spot missing dates or duplicate invoice numbers."

## Quick Prompt Upgrades (When Results Are Too Vague)

If Copilot gives a generic answer, add one of these lines:
- "Use plain English for a non-technical audience."
- "Keep this under 120 words."
- "Show the output as a table with columns: Owner, Action, Due Date."
- "Give me 2 options: one concise and one detailed."
- "Tell me what information is missing so I can add it."

---

## Data Safety Reminder (FinBridge Day 1 Habit)

From Day 1 of this programme: **treat data protection as a daily habit, not a one-off step**.

Most day-to-day drafting and summarising work is fine to do in Microsoft 365 Copilot.

- Use Microsoft 365 Copilot only within FinBridge-approved tools and accounts.
- Do **not** paste confidential client data into external/public AI tools.
- If you are unsure whether information is sensitive, pause and check with your manager or data owner.
- Share the minimum data needed to complete the task.

A safe way to ask:
"I need help drafting this update. I have removed client-identifying details. Please keep the wording general and professional."

---

## Final Tip

Start simple. If the first response is not right, do a second prompt with clearer Task, Context, Format, and Check. Most improvements come from one good follow-up instruction.
